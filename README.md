# Portal Mercado Erótico

Repositório oficial dos módulos customizados, tema editorial contemporâneo e integrações do Portal Mercado Erótico.

## Estrutura do Projeto
- `wp-content/themes/blocksy-child/`: Tema editorial contemporâneo (Bento Grid, Tipografia Editorial, Responsivo)
- `wp-content/mu-plugins/mercado-acervo.php`: Módulo dinâmico do Acervo Histórico (pesquisa e filtros de 2.115 artigos desde 2018)
- `wp-content/mu-plugins/mercado-livraria.php`: Vitrine digital de e-books, cursos e manuais
- `wp-content/data/livraria_clean.json`: Base de dados dos 54 produtos da livraria com dados higienizados

## Integração Contínua (Deploy Hostinger Git)
Este repositório pode ser conectado diretamente na Hostinger em **Avançado > Git** para atualizações automáticas e deploys com 1 clique.
